# canvai-hq

Instructions et contexte des agents de Canvai (routines Claude Code dans le nuage).
Dépôt privé. Aucune donnée client, aucune clé, aucun jeton : seulement des règles et des méthodes.

- `CLAUDE.md` : les règles que chaque agent lit en premier.
- `context/canvai.md` : ce que les agents doivent savoir sur Canvai.
- `context/organisation.md` : DOM, les 10 départements, les agents et leurs identifiants.
- `lessons-canvai.md` : les leçons apprises sur Meta, les textes de pubs et le Centre de commande.
- `skills/` : les fiches de méthode (campagnes Meta, créatifs, comment écrire dans le Centre de commande).

Source de vérité : l'OS de Seb (Dropbox). Ce dépôt en est une copie filtrée. Mise à jour à la main.
